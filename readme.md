# Dynamic Weather 🌤️

A simple and interactive React application that displays current weather details and dynamic greetings based on the time of day. Built to practice frontend skills and state management.

## ✨ Features

*   **Current Temperature:** Displays the current temperature clearly on the screen.
*   **Min & Max Tracking:** Shows the minimum and maximum temperatures for the day.
*   **Clean UI:** Simple and user-friendly interface.

## 🛠️ Technologies Used

*   **Frontend:** React.js
*   **Styling:** Tailwind CSS (v4.3)
*   **Language:** JavaScript (ES6+)
